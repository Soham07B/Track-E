# Track-E 📱

Track-E is a simple Android activity tracking application built with **Kotlin**.

The app allows users to record walking sessions, count steps, measure distance, and view their previous activity sessions.

## Features

- 🚶 Step counting using the accelerometer
- 📍 Distance tracking using GPS
- 📊 Activity history with a custom graph
- 📱 Daily accumulated step count
- 💾 Local data storage using SharedPreferences

## Technologies

- Kotlin
- Android Studio
- Android SDK
- Accelerometer Sensor
- GPS / Fused Location Provider
- RecyclerView
- Custom View
- SharedPreferences

## App Structure

- **MainActivity** — Dashboard and daily step count
- **TrackingActivity** — Step and distance tracking
- **HistoryActivity** — Previous sessions and activity graph

## Requirements

- Android 14 or higher
- Location permission
